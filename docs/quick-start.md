# 快速开始

## 前提条件

- Node.js 18.17 或更高版本。
- npm。
- 可选：一个可访问的 SubConverter 兼容服务。

## 本地运行

在 `Front` 目录执行：

```powershell
npm install
npm run dev
```

打开 `http://localhost:3000`。

开发模式用于管理和验证功能，转换后端页会显示“导出公共列表”按钮。该入口不会出现在生产构建中。

## 第一次转换

1. 打开“转换后端”，确认“本机 SubConverter”可用，或添加自己的 Provider。
2. 返回“订阅转换”，输入订阅链接、节点链接，或多行链接。
3. 选择目标客户端和 Provider。
4. 根据需要展开“高级转换选项”，选择远程配置或设置筛选规则。
5. 生成订阅链接，再复制或在新标签页打开配置。

多个来源支持每行一个，也支持使用 `|` 分隔。

## 本地数据

浏览器会持续保存 Provider、Profile、历史记录和设置。它们不是 session 数据，没有自动过期时间。数据会在以下情况消失：

- 手动删除、恢复默认或导入其他备份。
- 清除站点数据或浏览器配置文件。
- 无痕窗口关闭。

可在“设置 → 本地数据”导出或导入完整备份。
